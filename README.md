# 水下考古潜水记录

直接打开`index.html`使用。点击平面图添加标记，支持筛选、编辑、删除、时间线和导出JSON。

## 离线潜水减压剖面复核台

页面下方新增减压复核台，完全离线运行，手机与桌面均可完整录入：

- **分段录入**：连续下潜 / 停留 / 上升分段（目标深度 + 时长），可增删行；
- **模型**：ZHL-16C 十六组织半时，Schreiner 方程逐秒推进组织压力（`deco.js`）；
- **修正**：海拔（ISA 气压）、水温（灌注 / 溶解度启发式）、工作强度（吸氮加快、排氮减慢）、重复潜水残留氮（上一潜方形剖面 + 水面间隔模拟）；
- **梯度因子**：GF 低值控制首次停留深度，GF 高值控制出水上限，中间随深度线性插值；
- **方案起点**：减压方案从所有已录入分段结束后的真实深度与组织状态起算——离开最大深度后的浅层下潜 / 停留 / 回升都会改变后续负荷，TTS 与停留随之更新；结束深度不在 3 m 停留层时，剩余停留从结束深度继续，绝不停到比结束位置更深的层；
- **安全报警**：剖面结束时当前深度浅于减压上限（容差 5 cm），无论是否回到水面都立即红色报警；并按录入剖面**逐秒**比对当前深度与减压上限（与本潜最大减压义务同口径的梯度因子插值），途中越限立即报警并指出分段、深度与累计越限时长——越限后回潜也不能被合规的结束状态掩盖，正常上升与重复潜水入水残留不误报；
- **拒绝出结果**（并定位到具体分段行）：时间倒序、上升过快（>18 m/min）、分段类型与深度方向不符（停留段不得移动深度）、分段不足 1 秒、超出模型范围（深度 / 海拔 / 水温 / 梯度因子等）、减压迭代不收敛（指出所属分段与停留深度并高亮）；
- **结果**：总出水时间 TTS（自剖面结束状态起算）、减压停留表（3 m 步进）、16 舱室组织饱和度（全程峰值 + 剖面结束）、控制舱室、当前减压上限；任何参数改动立即重算。

> 仅供教学复核，不能替代潜水电脑表与正式减压计划。

## 文件结构

- `index.html` — 页面（记录工具 + 复核台界面与样式）
- `deco.js` — 减压计算引擎（纯逻辑，无 DOM，浏览器 / Node 共用）
- `deco-ui.js` — 复核台 DOM 接线（计算一律调用 `Deco.reviewProfile`）
- `test/deco.test.js` — 算法边界测试（解析解对照、四类拒绝、修正单调性、梯度因子、重复潜水、结束深度安全判断、途中越限逐秒检测）
- `test/browser.test.js` — Playwright 真实浏览器核验（非法剖面、重复潜水、即时重算、越限报警、移动端）

## 测试

```bash
npm test              # 算法边界测试（Node，无需浏览器）
npm run test:browser  # 真实浏览器核验（需先 npx playwright install chromium 及系统依赖）
```

无 root 权限的环境可参照本仓库验证过的做法：`apt-get download` 缺失的库并 `dpkg -x` 解压到本地目录，运行时设置 `LD_LIBRARY_PATH` 指向解压出的 `usr/lib/aarch64-linux-gnu` 与 `lib/aarch64-linux-gnu`。
